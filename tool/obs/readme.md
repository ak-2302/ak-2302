# OBS Widget Shelf

OBSのブラウザソース向けウィジェットをまとめた静的サイトです。
時計、カウンター、タイマー、メモ、スケジュールなどのウィジェットを、個別ページから確認・調整できます。

## 使い方

1. ローカルサーバーを起動します。

```sh
python3 -m http.server 8000
```

2. ブラウザで `http://localhost:8000` を開きます。
3. 一覧からウィジェットを選び、各ページのURLをOBSのブラウザソースに設定します。

## 必要な動作環境

- 近年のWebブラウザ
- Python 3.8以上
- OBS Studio

## 構成

- `index.html`: ウィジェット全体の入口
- `widgets/`: 各ウィジェットの一覧と本体
- `assets/`: 共通スタイルと一覧ページ用スクリプト

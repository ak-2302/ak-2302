配信情報を設定

接続について

  1. YouTubeはAPIキーと配信中の動画IDを指定します。
  2. Twitchはチャンネル名とOAuthトークンを指定します。
  3. ツイキャスは配信IDとAPIアクセストークンを指定します。
  4. APIキー・トークンはURLに含まれるため、公開配信では専用キーやプロキシの利用を推奨します。

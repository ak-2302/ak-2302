# 画像変換ツール

画像をブラウザ内で変換・リサイズ・補正するサーバーレス型の静的Webアプリです。画像ファイルは外部サーバーへ送信されません。

## 使い方

```sh
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173/tool/image_converter/` を開きます。

## 機能

- PNG / JPEG / WebP / AVIF変換
- 品質・圧縮率の調整
- 幅・高さ変更、縦横比維持
- ドラッグ＆ドロップによる複数画像追加
- 回転・反転、中央正方形トリミング
- 明るさ、コントラスト、色調補正
- 変換前後のプレビューと容量比較
- ZIP一括ダウンロード
- Canvas再出力によるEXIF情報の削除

## 動作環境

- Canvasと`toBlob`に対応したモダンブラウザ
- ZIP保存にはインターネット接続（JSZip CDN）が必要
- AVIF出力はブラウザの対応状況に依存

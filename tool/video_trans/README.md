# 動画変換ツール

複数の動画をブラウザ内でMP4へ一括変換するツールです。ファイルはサーバーへアップロードされません。

## 起動方法

WebAssemblyを正しく読み込むため、ローカルサーバー経由で開いてください。

```sh
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。

## 機能
- ファイルまたはフォルダ単位で動画を複数追加
- SHA-256による内容ベースの重複検出
- 連番または元ファイル名による重複しないリネーム
- ゼロ埋め桁数と開始番号の指定
- FFmpeg.wasmによるMP4変換
- ZIPまたは個別ファイルでのダウンロード
- 件数、合計サイズ、重複数、進捗の表示

## 構成

- `index.html`: 画面
- `index.css`: デザイン
- `index.js`: ファイル管理、重複判定、変換、ダウンロード

## 注意

- FFmpegとJSZipをCDNから読み込むため、初回起動時はインターネット接続が必要です。
- 変換は端末のメモリとCPUを使用します。長時間・大容量の動画では処理に時間がかかる場合があります。

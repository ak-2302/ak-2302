# GitHub Pagesの過去版を再現表示するWebアプリを作った話

GitHub Pages は静的サイトを簡単に公開できますが、過去のコミット時点の表示をそのまま見る仕組みはありません。  
そこで、公開リポジトリの履歴から `index.html` を取り出し、相対パスを張り直して、なるべく当時の見た目に近い形で再構成する Web アプリを作りました。

対象は公開リポジトリのみです。認証やトークンは使わず、ブラウザだけで動く構成にしています。

## できたもの

- GitHub Pages URL を入力
- コミット履歴を自動取得
- 直近 100 件から選択
- 未選択時は最新の公開ページを表示
- 表示中のページを新しいタブで開く
- 過去コミット版は sandbox 付き iframe でプレビュー

## ざっくり設計

実装はフレームワークなしの静的 HTML/CSS/JavaScript です。

```text
index.html  UI
styles.css   レイアウト
app.js       画面制御と取得処理
core.js      URL解析と書き換えロジック
```

コミット履歴は GitHub API から取得し、`index.html` は `raw.githubusercontent.com` から読みます。  
アセットは `cdn.jsdelivr.net/gh/...@SHA/...` に寄せて、コミット固定の参照先へ置き換えています。

## 実装でやったこと

### 1. Pages URL からリポジトリを推定

`https://username.github.io/` なら `username/username.github.io`、  
`https://username.github.io/repo/` なら `username/repo` と解釈します。

ユーザーサイトとプロジェクトサイトの両方に対応させました。

### 2. コミット履歴を自動取得

最初は SHA を手入力する形でしたが、使ってみると「どの SHA を入れればいいのか」が面倒でした。  
そこで GitHub API から直近 100 件を引いて、選択式にしました。

履歴取得に失敗しても、最新の公開ページはそのまま表示できます。  
「履歴が取れない = 何も見えない」にしないのが大事でした。

### 3. HTML を DOMParser で再構成

取得した HTML はそのままだと相対パスが壊れるので、DOM を走査して以下を書き換えています。

- `link[href]`
- `script[src]`
- `img[src]`
- `source[src]`
- `a[href]`
- `srcset`
- `style` 内の `url(...)`

`<base>` も注入して、相対参照が GitHub Pages 依存になりすぎないようにしました。

### 4. 安全に表示する

表示は `iframe` を使い、`sandbox` を付けています。  
JavaScript 実行は切り替えられるようにしましたが、基本は静的サイト向けです。

## つまずいた点

### GitHub Pages ではない URL をどう扱うか

最初は URL を雑に受けていましたが、これだと GitHub Pages 以外の入力も通ってしまいます。  
なので `github.io` ドメインかどうかを明示的に確認するようにしました。

### SPA やビルド済みサイトは完全再現できない

静的 HTML のサイトはかなり素直に再現できますが、SPA や SSR は別問題です。  
最終的には「完全再現ツール」ではなく「公開履歴を見やすくするツール」と割り切るのが現実的でした。

### 新しいタブで開く導線

表示結果をそのまま新しいタブで開けると、確認がかなり楽になります。  
過去コミット版は生成した HTML の Blob URL、最新ページは元の Pages URL を開くようにしました。

## 検証

ロジックは `node` のテストで確認しました。

```bash
npm test
```

ローカル表示は簡易サーバーで確認しています。

```bash
npm run serve
```

## まとめ

GitHub Pages の「過去の見た目をそのまま見る」体験は標準では弱いですが、  
公開リポジトリの履歴と静的ファイルの再構成を組み合わせると、かなり実用的なビューアになります。

今後やるなら、次はこんな拡張が考えられます。

- コミットメッセージ検索
- 画像や CSS の変換精度向上
- カスタムドメイン対応
- 履歴キャッシュ

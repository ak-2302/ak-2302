# OBSで使えるウィジェット集

# 構成
- index.html：OBSウィジェット全体のリンク
- widgets/[toolname]/index.html：各ウィジェットグループの一覧
- widgets/[toolname]/desigh_[number]/index.html：ウィジェットの調整とURL配布と使い方の説明
- widgets/[toolname]/desigh_[number]/core/index.html：ウィジェットの本体
- widgets/[toolname]/desigh_[number]/core/style.css：ウィジェットのスタイル

# 機能
- ウィジェットのデザイン一覧ページにリンクコピーボタンがある
- ウィジェットのダウンロードボタンがある
- ウィジェットの調整ページでURLにパラメータを設定する
- URLのパラメータをもとに、ウィジェットの色や縁取りや影を変更する
- 背景は透過だが、図形などでデザインを整える

# 起動方法
静的ファイルなので、ローカルサーバーを起動して利用できます。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。

# ウィジェット
## 時計・カレンダー
- 年月日時分秒のうち、便利な組み合わせで何種類かテンプレートを作る。

## カウンター
- 右と上の矢印とenterで数字を増やす
- 左と下の矢印とbackspaceで数字を減らす
- spaceで数字をリセットする
- UIのボタンはUP/DOWN/RESETのみ

## タイマー
- タイマーを設定する
- 時分秒のうち、便利な組み合わせで何種類かテンプレートを作る。
- UIのボタンはSTART/PAUSE/RESETのみ

## メモ
- シンプルなメモ
- 背景透過と背景ありを用意する
- 文字のスタイルをパラメータにする

## スケジュール
- スケジュールを表示する
- 背景透過と背景ありを用意する
- 左に下方向の矢印を用意し、右にパラメータで受け取ったスケジュールを表示する
